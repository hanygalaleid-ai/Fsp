# Fsp Battle Royale

مشروع لعبة Battle Royale ثلاثية الأبعاد خفيفة متعددة المنصات تستهدف:

- Android
- iOS
- Windows PC

## الرؤية

تجربة Battle Royale عربية الأصل، سريعة وخفيفة، بجرافيك واقعي محسّن للأجهزة المتوسطة، مع الحفاظ على جوهر النوع: منظور ثالث، أسلحة، Loot، Backpack، دروع وخوذ، Safe Zone، Airdrop، مركبات، Bots، Solo/Squad، Ranking وSkins.

## أهداف النسخة الأولى

- 32 لاعبًا كهدف أولي للمباراة مع Bots لملء الأماكن الفارغة.
- Squad Voice عبر Cloudflare Realtime/WebRTC.
- Supabase للحسابات والملفات الشخصية والـInventory والنتائج.
- Cloudflare للـAPI والحماية والخدمات اللحظية الخفيفة.
- GitHub لإدارة السورس والإصدارات وCI.
- خريطة واحدة محسّنة بدل خرائط كثيرة في البداية.
- إعدادات Low / Medium / High مع هدف أداء 60 FPS على الأجهزة المتوسطة حيث تسمح العتاد والظروف.

## حالة المشروع

Bootstrap أولي. سيتم استيراد أساس Unity/Megacity-compatible architecture ثم تحويله تدريجيًا إلى Third-Person Battle Royale خاص بالمشروع.

## قواعد مهمة

- لا يتم استخدام أصول PUBG أو اسمها أو علاماتها التجارية.
- كل الهوية البصرية والشخصيات والخرائط والأسلحة ستكون أصلية أو مرخّصة للاستخدام التجاري.
- يتم فصل Game Server عن قاعدة البيانات من البداية لتسهيل التوسع لاحقًا دون إعادة بناء التطبيق.
