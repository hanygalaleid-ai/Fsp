# Fsp Free Starter Cosmetics

These are original starter concepts for the first playable build. Final meshes/textures must be created in-house or from assets with licenses compatible with commercial redistribution.

## Set A — Coastal Ranger (default free)
- `default_head_coastal_ranger`: short practical hair / neutral cap-free head option.
- `default_face_coastal_ranger`: clean face option without branded masks.
- `default_torso_coastal_ranger`: sand field jacket with deep-navy inner layer and restrained bronze zipper accents.
- `default_legs_coastal_ranger`: charcoal utility trousers with sand knee panels.
- `default_backpack_coastal_ranger`: compact navy canvas field pack.
- `default_parachute_coastal_ranger`: sand canopy with navy geometric edge pattern.

## Set B — Quarry Scout (free unlock)
- `starter_head_quarry_scout`: wrapped neck scarf / simple head variant.
- `starter_torso_quarry_scout`: limestone-grey overshirt with rolled sleeves.
- `starter_legs_quarry_scout`: dusty olive work trousers.
- `starter_backpack_quarry_scout`: small quarry-worker inspired pack, fictional markings only.
- `starter_parachute_quarry_scout`: muted grey canopy with original angular pattern.

## Set C — Port Runner (free unlock)
- `starter_head_port_runner`: original short-hair/headwear variant.
- `starter_torso_port_runner`: deep-navy lightweight jacket with sand shoulder panels.
- `starter_legs_port_runner`: faded dark utility trousers.
- `starter_backpack_port_runner`: compact rope-and-canvas inspired pack without real brands.
- `starter_parachute_port_runner`: navy canopy with bronze/sand stripe geometry.

## Art rules
- No camouflage pattern copied from another game.
- No real-world military unit insignia, weapon-manufacturer logos, sports/fashion marks, or country military badges.
- Material language stays stylized-realistic and mobile-friendly.
- Starter items should share atlases where possible to reduce draw calls and build size.
