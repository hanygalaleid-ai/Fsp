## Starter attachments
- Sandglass 1.5x optic: modest zoom, no stat boost beyond ADS FOV.
- Port Brake: -12% vertical recoil, slightly louder visual signature only if desired later.
- Compact Grip: -10% horizontal recoil, -5% spread.
- Field Mag: +5 rounds, +6% reload time.

These are initial balance targets only. Final tuning must use playtest telemetry rather than copying another game's weapon values.
